# Desafios de PHP

Espaço para exercícios que reforçam os conceitos apresentados nos estudos.

## Organização

Cada desafio deve informar:

- O objetivo do exercício.
- Os conhecimentos necessários.
- Exemplos de entrada e saída, quando aplicável.
- A solução em um arquivo PHP executável.

Os desafios podem ser agrupados por assunto conforme forem adicionados, por exemplo `arrays/`, `strings/` e `orientacao-a-objetos/`.

Ainda não há desafios cadastrados.
